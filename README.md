# multimodal-money-printer

**멀티모달 AI 데이터 기반 그로스 마케팅** 강의의 강의자료와 실습 리소스를 모아 두는 저장소입니다.

마케터를 준비하는 비전공 취업준비생이 AI와 데이터로 광고 성과를 읽고, 근거를 갖춰 개선안과 실험을 제안하도록 돕는 10회 80시간 과정입니다. 과정 설계의 전체 근거와 결정 사항은 [강의 기획서](docs/course-plan.md)에 있습니다.

## 과정 개요

| 항목 | 내용 |
| --- | --- |
| 대상 | 마케터를 준비하는 비전공 취업준비생, 4인 1팀 |
| 일정 | 월·수·금 10회, 총 80시간(회당 8시간: 오전 이론·시연, 오후 팀 프로젝트) |
| 방식 | 오프라인, 팀당 Meta 광고 예산 50만원으로 직접 집행 |
| 결과물 | 분석 리포트, 대시보드, 자동화 워크플로우 보고서(포트폴리오용) |
| 주요 도구 | GA4(데모 계정·BigQuery 샘플), Looker Studio, Meta Ads Manager, Meta Model API(SAM 3.1, Muse Image, Muse Spark) |

## 학습목표

1. **진단과 개선안:** 직접 집행한 Meta 광고 데이터와 GA4 데이터를 근거로 퍼널 지표를 해석해 문제 지점을 찾고, 근거와 우선순위를 붙인 개선안 3개를 리포트와 대시보드로 제시할 수 있다.
2. **실험 설계와 판정:** 팀 예산으로 확보 가능한 표본을 계산해 클릭률 A/B 실험을 설계하고, 유의성 검정으로 판정해 "이 데이터로 말할 수 있는 것과 없는 것"을 구분해 설명할 수 있다.
3. **AI 활용과 검증:** 멀티모달 AI의 소재 해석과 변형 소재를 성과 데이터로 검증해 채택 여부를 판단하고, 자동화 워크플로우로 반복 가능한 보고 체계를 만들 수 있다.

예측 모델링과 시뮬레이션은 맛보기로만 다룹니다.

현재는 `docs/`만 있고, 나머지는 자료가 생기는 대로 추가할 예정입니다.

```text

├── scripts/             # (예정) 소재 일괄 측정 스크립트, 두 비율 검정 계산 시트
└── assets/              # (예정) 강사 제작 광고 소재 이미지
```

## 자료를 올릴 때 지킬 것

- **API 키와 계정 정보는 커밋하지 않습니다.** Model API 키는 환경 변수(`MODEL_API_KEY`)로만 다루고, `.env` 파일은 `.gitignore`에 들어 있습니다.
- **소재 이미지는 강사 제작 또는 수강생 본인 소재만 올립니다.** 타사 광고와 인물 사진은 저작권과 초상권을 확인하기 전에는 올리지 않습니다.
- **수강생 개인정보와 팀 광고 계정 데이터는 올리지 않습니다.** 실습용 데이터는 익명화하거나 강사가 만든 샘플을 씁니다.
- **Muse Spark는 Standard 모드만 씁니다.** Contributor 모드는 입력 내용을 Meta 모델 학습에 쓰도록 허락해야 합니다.
